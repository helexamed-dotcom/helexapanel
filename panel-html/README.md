# پنل دانشجویی (HTML)

یک پروژه‌ی کاملاً مستقل و ایستا (فقط HTML/CSS/JS) که صفحه‌ی اصلی و صفحه‌ی «دسترسی»
سامانه را بازسازی می‌کند. هیچ وابستگی بیرونی (CDN، فونت آنلاین، کتابخانه) ندارد و
آفلاین هم بدون خطا کار می‌کند.

## ساختار

```
panel-html/
├── index.html                 صفحه اصلی + صفحه دسترسی (لایه تمام‌صفحه)
└── assets/
    ├── css/style.css          تمام استایل‌ها
    ├── js/app.js              باز/بسته شدن دسترسی + جستجوی کاشی‌ها
    └── img/
        ├── logo.svg           آرم هدر
        └── avatar.svg         تصویر پیش‌فرض دانشجو
```

## اجرا

فایل `index.html` را مستقیم در مرورگر باز کنید، یا:

```bash
cd panel-html
python3 -m http.server 8000
# http://localhost:8000
```

## بخش‌ها

- **هدر**: دکمه «دسترسی»، آرم وسط، شمارنده پیام (44)، حساب کاربری، خروج.
- **خوش آمدید**: مشخصات دانشجو + تصویر.
- **پیام‌ها**: جدول پیام‌ها به همراه صفحه‌بندی.
- **اخبار قابلیت‌ها و اصلاحات**.
- **لاگ ورود**: جدول ورودهای موفق.
- **دسترسی**: با کلیک روی «دسترسی» باز می‌شود؛ نوار جستجو + کاشی‌های رنگی.
  بستن با دکمه «دسترسی»، کلیک روی فضای تیره یا کلید Esc.

> کاشی‌های ردیف آخر (کارنامه مالی / پرداخت برخط / کتابخانه دیجیتال) در تصویر
> مرجع بریده شده بودند؛ عنوان دو موردِ کناری قابل ویرایش است.
