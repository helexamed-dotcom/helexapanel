این پوشه محل تصاویر برند و آیکون‌هاست: لوگو، آواتار پیش‌فرض مرد/زن، و آیکون دوره‌ها.

می‌توانید فایل PNG یا SVG را مستقیماً همین‌جا (یا داخل `courses/` برای آیکون دوره‌ها) با
FTP یا فایل‌منیجر قرار دهید، یا از پنل مدیریت → تنظیمات → «برند و تصاویر» آپلود کنید.
هر دو راه در همین پوشه ذخیره می‌شوند و از یک لیست مشترک در پنل قابل انتخاب‌اند.

فایل‌های SVG قبل از ذخیره پاکسازی می‌شوند (حذف اسکریپت و رویدادهای درون‌خطی) تا صرفاً
یک تصویر برداری امن باقی بمانند.
